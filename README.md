# AlfaLearn

Telegram-помощник для предпринимателей по материалам Альфа-Курса.

Бот отвечает только по проверенному корпусу, показывает источник, рекомендует
материалы Альфа-Курса и создаёт разовые или повторяющиеся напоминания после
явного подтверждения пользователя.

## Быстрый запуск

Требования: Docker с Docker Compose, NVIDIA GPU и доступ в интернет для первой
загрузки локальной модели.

```bash
git clone https://github.com/cont1n3nt/AlfaLearn.git
cd AlfaLearn
cp .env.example .env
```

В `.env` укажите только токен тестового Telegram-бота:

```env
BOT_TOKEN=...
```

```bash
docker compose up --build
```

При первом запуске Compose скачивает и проверяет локальную модель. Это занимает
время и требует около 6 GB места для модели. Бот начинает polling после
готовности модели.

Проверка состояния:

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/ready
```

`/ready` возвращает `200` и статус `ready`, когда polling, корпус, напоминания
и закреплённая модель готовы.

Остановка:

```bash
docker compose down
```

## Что проверить

1. «Какой принтер этикеток выбрать для длительного хранения товара на Ozon?» —
   ответ по источнику и материал.
2. Точная стоимость доставки за город — честный отказ без выдуманного числа.
3. Бесплатный или платный курс по УСН на маркетплейсах — карточка со ссылкой и
   типом доступа.
4. Напоминание — дата, время, `Europe/Moscow`, подтверждение «да», затем
   доставка; повтор можно изменить или отменить.

## Архитектура

```text
Telegram → aiogram → диалог / SQLite → проверенный корпус → локальная Ollama
                                            ↓
                                   источник и рекомендация
                                            ↓
                              подтверждённое напоминание → Telegram
```

В образ входят 133 фрагмента 21 публичной статьи и 12 вручную проверенных
фрагментов подкаста. Платные уроки, исходная выгрузка, персональные данные и
секреты в корпус не входят. Ответ без подтверждённого источника не выдаётся.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота. Обязателен для polling. |
| `AI_REQUEST_TIMEOUT` | Максимальное время ответа модели. |
| `AI_HTTP_TIMEOUT` | Таймаут HTTP-вызова Ollama. |
| `REMINDERS_PATH` | Путь SQLite-хранилища напоминаний. |

Остальные переменные и безопасные значения приведены в `.env.example`.

## Ограничения

- Нужен GPU: текущая локальная модель на CPU может отвечать слишком долго.
- При недоступной Ollama `/ready` возвращает `503`; бот не заменяет ответ
  неподтверждёнными общими знаниями.
- Подкастный корпус содержит один вручную проверенный выпуск.
- Для проверки нужен собственный токен Telegram-бота; его нельзя добавлять в
  репозиторий или архив.
