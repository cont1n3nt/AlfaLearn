# AlfaLearn — АльфаНавигатор

Минимальный Telegram-бот для кейса «Альфа-Курс»: будущий помощник по обучающим
материалам для предпринимателей. Сейчас реализованы проверка связи Hello World,
заглушки для 18 типов сообщений и один ответ на группу сообщений. Поиск, LLM,
профиль и напоминания пока не подключены.

Бот: [@AlfaLearnBot](https://t.me/AlfaLearnBot).
Отображаемое имя: **АльфаНавигатор**.
Первый проверенный username `AlfaLearnBot` оказался свободен. Другие варианты
для названия: «КурсНавигатор», «АльфаМаршрут».

## Запуск на Windows

Для проекта используется Python 3.11 и доступ к Telegram API. Версия закреплена
в `.python-version`. Команды ниже создают окружение на Python 3.11. Из корня проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Укажи токен BotFather в `BOT_TOKEN` в `.env`. В текущем рабочем проекте `.env`
уже заполнен — не перезаписывай его примером.

```powershell
.\.venv\Scripts\python.exe -m alfalearn
```

Один процесс запускает FastAPI и Telegram long polling. Публичный домен,
HTTPS-туннель и webhook для локального запуска не нужны. Запускай только один
экземпляр бота и один worker. Остановка: `Ctrl+C`.

### Задержка ответа

Бот отвечает через **2 секунды после последнего сообщения**, объединяя сообщения
пользователя в один общий ответ. Каждое новое сообщение продлевает ожидание.
Задержка задаётся в `.env`: `GROUP_DELAY_SECONDS=2` (от 0.1 до 30 секунд).
После изменения настройки перезапусти бота.

## Что проверить

- `GET http://127.0.0.1:8000/hello` → `{"message":"Hello, world!"}`.
- `GET http://127.0.0.1:8000/` → тот же ответ.
- `GET http://127.0.0.1:8000/health` → состояние процесса polling и username.
- `POST http://127.0.0.1:8000/answers` → заглушка ответа на сообщение пользователя.
- [Swagger UI](http://127.0.0.1:8000/docs) — документация HTTP API.
- В Telegram: одиночный `/start` — приветствие; `/hello` и `/help` — `Hello, world!`.
- Обычный текст и неизвестная команда → `Извините я пока-что не могу читать ваши сообщения`.
- Голосовое, фото, видео и другие типы → соответствующая заглушка (см. ниже).
- Несколько сообщений подряд или альбом → один общий ответ после паузы в 2 секунды.

```powershell
Invoke-RestMethod http://127.0.0.1:8000/hello
Invoke-RestMethod http://127.0.0.1:8000/health
```

## Ответы

`POST /answers` принимает JSON с непустым строковым полем `message`:

```json
{"message": "Как начать обучение?"}
```

Ответ HTTP 200:

```json
{"answer": "Извините я пока-что не могу читать ваши сообщения"}
```

Если `message` отсутствует, пустое или имеет другой тип, API возвращает HTTP 422.
В Swagger этот эндпоинт находится в разделе «Ответы». Пример для PowerShell:

```powershell
$body = @{ message = "Как начать обучение?" } | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:8000/answers -Method Post `
  -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

### Отдельные типы

Все маршруты ниже используют `POST`, не требуют тела запроса и возвращают JSON
`{"answer": "..."}` с соответствующей заглушкой. Это проверка текста ответа по
известному типу: загружать файлы через HTTP пока не требуется.

| Тип сообщения | Маршрут | Что бот пока не умеет |
|---|---|---|
| Текст | `/answers/text` | Читать сообщения |
| Голосовое | `/answers/voice` | Прослушивать голосовые сообщения |
| Фото или скриншот | `/answers/photo` | Просматривать фотографии и скриншоты |
| Документ или файл | `/answers/document` | Читать документы и файлы |
| Ссылка | `/answers/link` | Открывать и читать ссылки |
| Видео | `/answers/video` | Просматривать видео |
| Видеокружок | `/answers/video-note` | Просматривать видеокружки |
| Аудиофайл | `/answers/audio` | Прослушивать аудиофайлы |
| Стикер | `/answers/sticker` | Распознавать стикеры |
| GIF | `/answers/gif` | Просматривать GIF-анимации |
| Эмодзи | `/answers/emoji` | Интерпретировать эмодзи |
| Контакт | `/answers/contact` | Обрабатывать контакты |
| Геолокация | `/answers/location` | Обрабатывать геолокацию |
| Пересланный текст или вложение | `/answers/forwarded` | Читать пересланные сообщения и вложения |
| Ответ на сообщение этого бота | `/answers/reply` | Обрабатывать ответы на свои сообщения |
| Сообщение с цитатой | `/answers/quote` | Читать сообщения с цитатами |
| Альбом фотографий или видео | `/answers/album` | Просматривать альбомы фотографий и видео |
| Вложение с подписью | `/answers/caption` | Обрабатывать вложения с текстовыми подписями |

Например, `POST /answers/voice` вернёт:

```json
{"answer": "Извините, я пока не могу прослушивать голосовые сообщения."}
```

### Группы сообщений

`POST /answers/group` принимает список типов. Можно повторять тип для нескольких
сообщений одного вида. Все 18 значений соответствуют последней части маршрутов выше.

```json
{"types": ["photo", "voice", "photo"]}
```

Ответ HTTP 200 — один текст, типы не повторяются:

```json
{"answer": "Извините, я пока не могу обработать эту группу сообщений: голосовое сообщение, фото или скриншот."}
```

Список должен содержать от 1 до 100 известных типов, иначе API возвращает HTTP 422.
HTTP-маршруты возвращают ответ вызывающему клиенту сразу и не отправляют сообщения в Telegram.

В Telegram типы определяются автоматически по полям сообщения, а не содержимому
файлов. У одного сообщения может быть несколько типов: например, пересланное фото
с подписью. Ссылки определяются по Telegram entities `url`/`text_link`, эмодзи —
по тексту без обычных слов. Цитаты поддерживаются как поле `quote` и как форматирование
`blockquote`/`expandable_blockquote`. GIF с дополнительным полем `document` остаётся GIF.

Бот собирает сообщения одного отправителя в одном чате и теме до паузы
`GROUP_DELAY_SECONDS` после последнего сообщения, затем отправляет **один ответ**.
Новое сообщение продлевает ожидание. Альбом, одинаковые или смешанные типы
обрабатываются тем же буфером. Другие пользователи, чаты и темы не смешиваются.
После завершения паузы следующие сообщения образуют новую группу. Команды также
участвуют в группировке: одиночная команда сохраняет свой ответ, команда вместе
с вложением получает общий ответ группы.

Тексты ответов и определение типов находятся в `alfalearn/answers.py`; буфер —
в `alfalearn/grouping.py`. Файлы не скачиваются, ссылки не открываются, содержимое
не сохраняется в базу. Буфер хранится в памяти: при остановке процесса ожидающие
ответы отменяются, при следующем запуске группы создаются заново.

## Калькуляторы

`/calc` присылает список всех калькуляторов Альфа-Курса с кнопками. У каждого
калькулятора есть своя команда; она присылает карточку: что считает калькулятор,
что в него ввести, формулы и пример со страницы сайта, и кнопку-ссылку на сам
калькулятор. Бот в карточках ничего не считает.

| Команда | Калькулятор |
|---|---|
| `/nds` | [Калькулятор НДС](https://kurs.alfabank.ru/calculators/nds/) |
| `/procent` | [Калькулятор процентов](https://kurs.alfabank.ru/calculators/raschet-procentov/) |
| `/propis` | [Сумма прописью онлайн](https://kurs.alfabank.ru/calculators/summa-propisyu-online/) |
| `/dni` | [Калькулятор календарных и рабочих дней](https://kurs.alfabank.ru/calculators/rabochie-dni/) |
| `/nalog` | [Выбор системы налогообложения для ИП и ООО](https://kurs.alfabank.ru/calculators/kalkulyator-sistem-nalogooblozheniya/) |
| `/zarplata` | [Калькулятор зарплаты](https://kurs.alfabank.ru/calculators/zarplata/) |
| `/ndfl` | [Калькулятор НДФЛ](https://kurs.alfabank.ru/calculators/ndfl/) |

Тексты карточек — в `alfalearn/calculator_cards.py` (написаны по страницам
калькуляторов из базы Альфа-Курса), команды и кнопки — в
`alfalearn/calculator_menu.py`. Чтобы команды появились в меню Telegram, после
обновления один раз запустите `python -m scripts.configure_bot`.

## Вопросы про НДС

Сообщение со словом «НДС» (или «налог на добавленную стоимость») получает
отдельный ответ сразу, без паузы буфера. Например, на «Сколько НДС заплатить
с 100 тысяч?» бот:

1. объясняет, кто платит НДС и какие бывают ставки;
2. считает НДС для суммы из вопроса по ставке 22%: сверху
   (`Сумма × 22 / 100`) и внутри суммы (`Сумма × 22 / 122`);
3. ссылается на источник — «Калькулятор НДС» Альфа-Курса;
4. предлагает статью и курс по теме;
5. показывает кнопки «Я на УСН», «Я на ОСН», «Не знаю свой режим» — они
   присылают уточнение с расчётом по ставкам режима (5% и 7% или 22% и 10%) —
   и кнопки-ссылки на калькулятор НДС и курс.

Сумма ищется в тексте: «100 тысяч», «100к», «87 500 ₽», «1,5 млн»; проценты и
годы пропускаются. Если суммы нет, бот показывает формулы и просит её написать.
Тексты и факты взяты со страницы калькулятора НДС, ссылки на статью и курс — из
базы Альфа-Курса. Код: `alfalearn/vat_answer.py` (текст и расчёт) и
`alfalearn/vat_bot.py` (обработчики и кнопки Telegram).

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Секретный токен из BotFather |
| `BOT_ENABLED` | `true` | `false` запускает только HTTP API без Telegram |
| `HOST` | `127.0.0.1` | Адрес HTTP-сервера |
| `PORT` | `8000` | Порт HTTP-сервера |
| `GROUP_DELAY_SECONDS` | `2` | Пауза после последнего сообщения перед общим ответом, от 0.1 до 30 секунд |

Переменные окружения имеют приоритет над `.env`. Сервер проверяет токен и
отсутствие webhook перед запуском. Если webhook уже настроен, запуск завершится
с ошибкой: конфигурацию Telegram нужно сначала переключить на polling.
Если задача polling остановится после запуска, `/health` вернёт HTTP 503.

`.env`, виртуальное окружение, настройки IDE, логи и локальные выгрузки базы
исключены из Git. В репозитории хранится только `.env.example` без ключа.

Локальные `.env` и `.venv/` содержат токен/настройки и установленное окружение.
Каталоги `.run/`, `.vscode/`, `.pytest_cache/` и `__pycache__/` — настройки
запуска, редактора и автоматически созданные кэши; они исключены из Git.

### Как связаны компоненты

1. `python -m alfalearn` вызывает `__main__.main()`, читает `Settings` и запускает Uvicorn.
2. `api.create_app()` создаёт FastAPI с маршрутами `/`, `/hello`, `/health`, `/answers`
   и `/answers/...` для отдельных типов и группы.
3. При старте FastAPI его `lifespan` проверяет токен и отсутствие webhook, затем
   запускает `Dispatcher.start_polling()` в фоновой задаче того же процесса.
4. `bot.create_dispatcher()` регистрирует обработчики: сначала команды, затем остальные
   сообщения. Они передают сообщения в `AnswerBuffer`; после паузы `message.answer()`
   отправляет один ответ в исходный чат и тему.
5. `/health` проверяет состояние задачи polling; при остановке приложения задача
   отменяется, а сессия Telegram закрывается. При `BOT_ENABLED=false` работает только HTTP API.

Базы данных, отдельного фронтенда и интеграции с LLM в проекте пока нет.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты проверяют HTTP-ответы и валидацию, все 18 типов, команды, альбомы,
смешанные группы, продление паузы, разделение чатов/пользователей/тем и отмену
ожидающих ответов при остановке. Запросы к Telegram заменены моками.
Для повторной настройки имени, публичного описания и
команд бота (токен берётся из `.env`):

```powershell
.\.venv\Scripts\python.exe -m scripts.configure_bot
```

Основные зависимости зафиксированы в `requirements.txt`; полный снимок
проверенного окружения, включая тестовые зависимости, — `requirements.lock`.
Для его воспроизведения: `python -m pip install -r requirements.lock`.

Документация: [aiogram polling](https://docs.aiogram.dev/en/latest/dispatcher/long_polling.html),
[FastAPI lifespan](https://fastapi.tiangolo.com/advanced/events/).
