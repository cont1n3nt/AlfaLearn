# AlfaLearn AI/ML

Модуль для консультаций по материалам Альфа-Курса. Возвращает ответы с источниками, подбирает учебные материалы, извлекает сведения о бизнесе из диалога и предлагает параметры напоминаний. Для подкастов ответ включает интервал записи.

## Запуск

Нужны Python 3.12, uv, допущенный корпус и запущенная локальная Ollama с моделью из [.env.example](.env.example).

```powershell
uv sync --locked
uv run --locked alfa-ai --query "Нужно обсудить ошибку подчинённого: наедине или при коллегах?"
uv run --locked alfa-ai --recommend-only --query "Есть курс по УСН для селлеров на Ozon?"
```

По умолчанию корпус статей читается из `data/local/pilot_chunks.jsonl`. Пути и параметры модели задаются переменными окружения. Для файла окружения используй `uv run --locked --env-file .env alfa-ai --query "…"`. Подключение расшифровок и локального E5 описано в [инструкции по подкастам](docs/ai/PODCASTS.md).

## Структура

| Путь | Назначение |
| --- | --- |
| `src/alfa_ai/` | Устанавливаемый модуль. `AIService` и типы запроса и ответа экспортируются из `alfa_ai`. |
| `scripts/` | Подготовка корпуса, импорт расшифровок и оценка качества. |
| `tests/` | Автономные тесты и контрольные вопросы. |
| `docs/ai/` | Контракт для бота, запуск и результаты проверок. |
| `data/local/` | Локальные корпуса, веса и отчёты. Папка исключена из Git. |

При запуске бот создаёт один `AIService`, передаёт ему запросы и закрывает при остановке. [Контракт Python API](docs/ai/INTEGRATION.md) описывает установку, профиль, напоминания и обработку ошибок.

## Подготовка корпуса

`compose.restore.yaml` запускает PostgreSQL и Adminer для локального восстановления выданного организаторами архива. После восстановления выполни команды из раздела [«Воспроизведение из исходного архива»](docs/ai/LOCAL_ACCEPTANCE.md#воспроизведение-из-исходного-архива). Скрипты читают PostgreSQL и сохраняют JSONL в `data/local/`. Сервис допускает к ответам только фрагменты, совпавшие с контрольными суммами из `src/alfa_ai/reviewed.py`.

## Проверки

```powershell
uv run --locked python -m unittest discover -s tests -v
uv run --locked --group corpus python -m unittest discover -s tests/corpus -q
uv run --locked --group lint ruff check src scripts tests
uv run --locked --group lint ruff format --check src scripts tests
```

Тесты подготовки корпуса используют токенизатор E5 из кэша Hugging Face и скачивают его при первом запуске. Сквозные проверки на локальной модели описаны в [отчёте приёмки](docs/ai/LOCAL_ACCEPTANCE.md). [Исходный роадмап](docs/AI_ML_ROADMAP.md) содержит материалы разработки.
